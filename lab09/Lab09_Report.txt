1. Inodes and Metadata:

Renaming a file with mv within the same filesystem normally keeps the same inode because the filename is only a reference to the inode and its data.

2. POSIX Permissions:

Read, write, and execute for the owner (7), read and execute for the group (5), and no permissions for others (0) give:

750

Python: os.chmod(filename, 0o750)

3. The AI Context:

OS permissions protect model files at the kernel level. When the file was read-only, the OS blocked writing with PermissionError. This is more reliable than relying only on application-level error handling.
