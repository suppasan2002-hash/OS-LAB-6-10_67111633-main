1. FIFO vs LRU (Phase 2):

FIFO produced 9 page faults, while LRU produced 7. LRU performed better because it removes the page that has not been used for the longest time, keeping recently used pages in memory.

2. Understanding Thrashing (Phase 3):

The RAM-based scenario took 0.4276 seconds, while repeated disk access took 1.5123 seconds—about four times slower. This shows that thrashing reduces performance because the system spends time moving data between RAM and disk instead of processing it.

3. AI Engineering Decision:

Reducing batch_size lowers memory usage and decreases swapping. More data can remain in RAM, which reduces thrashing and improves AI workload performance.
